### **Screenshot Best Practices:**

✅ **DO:**
- Use real content (not placeholder text)
- Show key features and functionality
- Use professional, clean designs
- Ensure text is readable
- Show the app in action
- Use consistent branding/colors
- Show different screens/features

❌ **DON'T:**
- Include personal/sensitive information
- Use placeholder text ("Lorem ipsum")
- Include device frames (Apple adds them)
- Add watermarks or promotional text
- Show status bar (hidden automatically)
- Use blurry or low-quality images

### **How to Take Screenshots:**

**Option 1: iOS Simulator (Recommended)**
1. Open your app in iOS Simulator
2. Navigate to the screen you want
3. Use `Cmd + S` to save screenshot
4. Screenshots are saved in correct resolution automatically

**Option 2: Physical Device**
1. Open your app on iPhone/iPad
2. Navigate to the screen
3. Take screenshot: `Power + Volume Up` (or `Home + Power` on older devices)
4. Resize to required dimensions if needed

**Option 3: Design Tools**
- Use Figma, Sketch, or Photoshop to create mockups
- Export at exact required dimensions
- Ensure they look realistic
